1. OVERVIEW                                                    *gitu-overview*

gitU.vim is an interactive Git plugin for Vim, written in Vim9 script.
It is inspired by graphical Git viewers such as gitk and tig, providing a
responsive, multi-pane commit inspection interface and status staging directly
inside Vim.

Key Features:
- 3-pane interactive Git log viewer (:GitULog).
- Interactive Git status view (:GitUStatus / :GitU) with instant staging
  (`<<`), unstaging (`>>`), diff preview (`dd`), and 3-way vertical patch
  editing (`pp`).
- 3-way patch editor (HEAD | STAGE | CURRENT) directly editing the Git index.
- Asynchronous execution via Vim9 jobs to keep the editor responsive.
- Buffer-local keymaps and dedicated filetypes with syntax highlighting.

Requirements:
- Vim 9.0 or later (with `+vim9script` and `+job` support)
- `git` command in `$PATH`

2. INSTALLATION                                            *gitu-installation*

Using your favorite plugin manager:

vim-plug: >
    Plug 'yasuhiroki/gitU.vim'
<
minpac: >
    call minpac#add('yasuhiroki/gitU.vim')
<
Vim 8/9 packages: >
    git clone https://github.com/yasuhiroki/gitU.vim.git \
        ~/.vim/pack/plugins/start/gitU.vim
<

3. COMMANDS                                                    *gitu-commands*

:GitULog [args]                                                    *:GitULog*
    Opens the 3-pane interactive Git log viewer in a new tab page.
    Pass any arguments accepted by `git log`: >
        :GitULog
        :GitULog --all
        :GitULog --first-parent
        :GitULog -n 50
<   Command completion is available for common Git options.

:GitUStatus                                                      *:GitUStatus*
:GitU                                                                  *:GitU*
    Opens the interactive Git status viewer in a new tab page.

4. STATUS AND 3-WAY STAGING                                      *gitu-status*

In the :GitUStatus view, files are grouped into sections:
    - Changes to be committed (staged)
    - Changes not staged for commit (unstaged)
    - Untracked files

Key Mappings in status buffer:
    <<                  Stage the file under cursor (`git add`).
    >>                  Unstage the file under cursor (`git restore --staged`).
    dd                  Open diff preview for the file under cursor.
    pp                  Open 3-way vertical patch editor (`git add -p`).
    u                   Update / refresh the status view.
    q                   Close the status view.

The 3-Way Patch Editor (`pp`):
When pressing `pp` on a file line, a new tab opens with 3 vertical split panels:

    +-------------------+-------------------+-------------------+
    | [GitU:HEAD]       | [GitU:STAGE]      | [CURRENT]         |
    |                   |                   |                   |
    | Commit HEAD       | Git Index         | Worktree file     |
    | (read-only)       | (editable staging)| (read/write)      |
    +-------------------+-------------------+-------------------+

All 3 panels participate in Vim diff mode (`diffthis`).
- Center panel ([GitU:STAGE]) represents the Git index. You can pull changes
  from CURRENT using `do` / `diffget` or edit lines directly.
- Saving the STAGE panel (`:w`) automatically writes the object to Git
  object storage and updates the Git index via `git update-index`.
- Pressing `q` in any panel exits diff mode and closes the tab, returning
  to the status buffer with automatic refresh.

5. PANES AND KEYMAPS                                            *gitu-keymaps*

The :GitULog view consists of three synchronized panes:

    +-------------------+-----------------------------------+
    |                   | [GitU:Commit]                     |
    |                   | Commit info, author, date,        |
    | [GitU:Log]        | commit message, changed files     |
    | Graph & commits   +-----------------------------------+
    |                   | [GitU:Diff]                       |
    |                   | Unified diff of commit or         |
    |                   | selected changed file             |
    +-------------------+-----------------------------------+

Key Mappings in :GitULog:
    q                   Close the GitU view and cancel background jobs.
    u                   Update / refresh the current view.
    <Tab>               Cycle focus forward across panes.
    <S-Tab>             Cycle focus backward across panes.

In the [GitU:Log] pane:
    j / k               Navigate commits. Moving the cursor automatically
                        updates the commit detail and diff panes.
    <CR>                Force update details and diff for commit under cursor.

In the [GitU:Commit] pane:
    j / k               Scroll metadata or navigate changed file entries under
                        the "--- Files ---" section.
    <CR>                Jump focus to the diff pane, showing the diff for the
                        selected file under the cursor.

6. OPTIONS                                                     *gitu-options*

g:gitu_commit_height                                    *g:gitu_commit_height*
    Height (in rows) of the top-right commit detail pane in the :GitULog view.
    Set to 0 or negative to disable resizing and preserve equal splits.
    Default: 15

7. HIGHLIGHTS                                               *gitu-highlights*

Status view highlights:
    GitUStatusBranch         Branch information line. (default: Title)
    GitUStatusHeaderStaged   Staged changes header. (default: diffAdded)
    GitUStatusHeaderUnstaged Unstaged changes header. (default: diffRemoved)
    GitUStatusHeaderUntracked Untracked files header. (default: diffChanged)
    GitUStatusClean          Clean working tree notice. (default: Comment)
    GitUStatusSymbolAdded    'A' symbol. (default: diffAdded)
    GitUStatusSymbolModified 'M' symbol. (default: diffChanged)
    GitUStatusSymbolDeleted  'D' symbol. (default: diffRemoved)
    GitUStatusSymbolRenamed  'R' symbol. (default: diffChanged)
    GitUStatusSymbolUntracked '?' symbol. (default: PreProc)

Log pane highlights:
    GitULogGraph        Graph tree characters (*, |, /, \). (default: Delimiter)
    GitULogHash         Commit SHA hashes. (default: Identifier)
    GitULogRefs         Branch/tag reference names. (default: Statement)
    GitULogAuthor       Author names enclosed in <>. (default: Type)
    GitULogDate         Commit timestamp. (default: Comment)

Commit pane highlights:
    GitUCommitHeader    Header labels (Commit:, Author:, etc.). (default: Keyword)
    GitUCommitHash      Commit hash. (default: Identifier)
    GitUCommitRefs      Branch/tag references. (default: Statement)
    GitUCommitDivider   Divider before files (--- Files ---). (default: Title)
    GitUCommitStatusAdded    'A' file status indicator. (default: diffAdded)
    GitUCommitStatusModified 'M' file status indicator. (default: diffChanged)
    GitUCommitStatusDeleted  'D' file status indicator. (default: diffRemoved)
    GitUCommitStatusRenamed  'R' file status indicator. (default: diffChanged)
    GitUCommitFileAdded      File path for added files. (default: Directory)
    GitUCommitFileModified   File path for modified files. (default: Directory)
    GitUCommitFileDeleted    File path for deleted files. (default: Directory)
    GitUCommitFileRenamed    File path for renamed files. (default: Directory)

Diff pane highlights:
    GitUDiffAdded       Added lines (+...). (default: diffAdded)
    GitUDiffRemoved     Removed lines (-...). (default: diffRemoved)
    GitUDiffChanged     Changed indicators. (default: diffChanged)
    GitUDiffFile        File header lines (diff --git ...). (default: diffFile)
    GitUDiffMeta        Index and mode meta lines. (default: diffIndexLine)
    GitUDiffHeader      Diff headers (--- / +++). (default: diffSubname)
    GitUDiffHunk        Hunk boundary line (@@ ... @@). (default: diffLine)

==============================================================================
8. FILETYPES                                                   *gitu-filetypes*

    gitu-log            Buffer filetype for the Git commit graph pane.
    gitu-commit         Buffer filetype for the commit metadata pane.
    gitu-diff           Buffer filetype for the diff preview pane.
    gitu-status         Buffer filetype for the Git status viewer.
    gitu-stage-head     Buffer filetype for the HEAD panel in 3-way staging.
